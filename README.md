A Spring Boot backend service for managing subscription-based memberships with tiered benefits.
The system allows users to subscribe to plans (Monthly, Quarterly, Yearly), progress through tiers (Silver, Gold, Platinum), and unlock configurable benefits (free delivery, discounts, early access, priority support, etc.).

Swagger Embedded.
Clone -> ./mvnw clean install -> ./mvnw spring-boot:run -> http://localhost:8080/swagger-ui.html
